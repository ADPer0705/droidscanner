16 ROOTLESS DEVICE CONFIGURATION CHECKS

Beyond apps: audit the settings attackers exploit first.

Every check maps directly to the relevant Android Settings screen with OEM-resilient fallbacks across Pixel, Samsung One UI, Xiaomi HyperOS/MIUI, Oppo/OnePlus ColorOS, and Vivo.

Lock & Physical Safety

  • Secure Screen LockVerifies PIN, password, or biometric lock via KeyguardManager.
  • Lock-Screen OTP PrivacyFlags sensitive notifications visible before unlocking.
  • Auto-Lock & Stay AwakeCatches excessive screen timeouts and USB stay-awake mode.
  • Storage EncryptionReports exposed Android file-based encryption posture.

Network & Traffic Interception

  • User CA CertificatesLists exact Subject/Expiry of custom CAs that can inspect HTTPS.
  • Encrypted DNS (Private DNS)Flags plaintext DNS (off) or unfamiliar custom DoT hostnames.
  • System HTTP ProxyDetects global or JVM-level HTTP proxy endpoints.
  • Active VPN & Captive Wi-FiUses read-only local transport state to flag VPNs & sign-in Wi-Fi.

Roles, Keyboards & Control

  • Default Core RolesAudits provenance of Default SMS, Phone, Browser, and Launcher.
  • Keyboards, Autofill & AssistantFlags sideloaded networked keyboards (keylogger surface) & autofill.
  • Special Access HubLists active Accessibility, Device Admin, Notification, Overlay & Installers.
  • MDM / Work ProfilesDetects unexpected Device Owner or Profile Owner controllers.

OS Lifecycle & Build Hygiene

  • Security Patch RecencyFlags patches older than 120 days (Review) or 365 days (At Risk).
  • Android OS SupportFlags end-of-life Android versions no longer receiving AOSP patches.
  • USB & Wireless DebuggingFlags enabled Developer Options, ADB over USB, and Wireless ADB.
  • OS Build & Verifier HygieneFlags test-keys, userdebug/eng, and disabled verifier where readable.

VERIFIABLE PRIVACY & HONEST ENGINEERING

Offline enforced by the Android OS — not a toggle.

app/src/main/AndroidManifest.xml Sandbox Enforced 
<!-- Enforces zero network sockets even if SDKs request it -->
<uses-permission
    android:name="android.permission.INTERNET"
    tools:node="remove" />

<!-- Read-only local transport state (VPN & captive Wi-Fi) -->
<uses-permission
    android:name="android.permission.ACCESS_NETWORK_STATE" />

<!-- App inventory & Android 9+ system uninstall dialog -->
<uses-permission
    android:name="android.permission.QUERY_ALL_PACKAGES" />
<uses-permission
    android:name="android.permission.REQUEST_DELETE_PACKAGES" />

Cloud backup & device transfer are disabled (allowBackup="false") and local snapshots, trusted records, embeddings, and audit timelines are explicitly excluded.

Honest Rootless Boundaries

Security tools lose trust when they fake checks Android doesn't allow. DroidScanner distinguishes Protected, Needs attention, and Not available.

VERIFIED
Public Android APIs

Permissions, live Accessibility / Notification / Device Admin registries, signing certs & v1–v3.1 blocks, DEX bytecode, Private DNS, CA store, lock screen, and optional Usage Stats.

HONEST LIMIT
Privileged / Hardware Claims

Without root or remote hardware attestation, no standard app can reliably prove bootloader lock state, kernel integrity, or Google Play Protect status. DroidScanner labels these limits instead of guessing.
